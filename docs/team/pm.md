# Product Manager (PM) Role & Responsibilities

- Ensures all work adheres to the Product Specification (`docs/spec.md`).
- Manages the task backlog (`tasks.md`) and tracks overall milestone progress.
- Enforces strict feature boundaries: local-first execution, no unwanted cloud LLM dependencies, separation between Dictation and Control modes.
- Verifies that issue descriptions, acceptance criteria, and resolution summaries are accurate.
